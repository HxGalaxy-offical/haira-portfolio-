Roadmap

Six builds to prove out full-stack + IoT

These aren't built yet — they're the plan. Each is scoped to be realistic with Java, HTML, CSS and JavaScript, and each deliberately borrows something from an internship or competition so the project reads as "informed by experience," not just "another tutorial clone."

01 · Web app + database

StudyDesk — Personal Study & Task Tracker

A task and study-session tracker for students: log subjects, deadlines, and time spent, with a running streak counter.

  • CRUD for tasks/subjects with due dates and priority levels
  • Study-session timer that logs completed sessions to the database
  • Simple login so data persists per user
  • Weekly summary view (tasks completed, hours logged)
Java (Servlets/Spring Boot) — backend + business logic MySQL — persistence HTML/CSS/JS — UI + timer logic
02 · Data visualization

Skill Growth Dashboard

An interactive dashboard visualizing your own learning journey — skills, certificates and internships plotted over time.

  • Timeline chart of certificates/internships by date
  • Skill radar or bar chart with filters by category (language, framework, tool)
  • Click a data point to see the certificate or internship it represents
  • Data loaded from a simple JSON file so it's easy to update
JavaScript (Chart.js or D3) — visualization HTML/CSS — layout Java — optional backend to serve data via a small API
03 · REST API project

Campus Events API + Client

A REST API for posting and browsing college events (workshops, competitions, seminars), with a clean JS frontend consuming it.

  • Endpoints: create/list/update/delete events, RSVP count
  • Filtering by category (workshop, competition, seminar) and date
  • Frontend fetches and renders via the Fetch API — no page reloads
  • Basic input validation and error responses (400/404) handled gracefully in the UI
Java (Spring Boot) — REST API MySQL/MongoDB — storage JavaScript (Fetch API) — client
04 · Original platform clone

MicroCourse — A Course Marketplace, Reimagined

Not a straight Udemy clone — take the marketplace layout you already practiced and add an original angle: peer-taught micro-courses (15–30 min lessons) for classmates.

  • Course listing with search and category filters
  • Instructor "create a course" flow (title, description, short lesson list)
  • Progress tracking per enrolled course (checkboxes → progress bar)
  • Responsive card grid that reflows cleanly from desktop to mobile
Java or Node.js — backend, whichever you want to strengthen MongoDB — flexible course/lesson documents HTML/CSS/JS — responsive UI
05 · Real-time collaboration

Group Study Room

A live room where a small group can chat and co-edit a shared notes panel in real time — useful for exam-prep groups.

  • Real-time chat per room using WebSockets
  • Shared text/notes area that updates live for everyone in the room
  • Simple room codes to join instead of full auth (keeps scope realistic)
  • "Who's online" indicator
Node.js + Socket.io — real-time layer JavaScript — client-side sync logic HTML/CSS — room UI
06 · Problem-solving utility

IoT Dashboard Simulator

Since real sensor hardware isn't always available, simulate an IoT dashboard: a backend that generates realistic sensor data (temperature, humidity, motion) and a frontend that visualizes it live.

  • Java service that simulates sensor readings on an interval
  • Live-updating charts and threshold alerts (e.g. "temperature too high")
  • Device list with online/offline status
  • Clean, dashboard-style UI — a direct place to apply the UI/UX principles from your design webinar
Java — data simulation logic JavaScript (Chart.js + polling or WebSockets) — live dashboard HTML/CSS — layout, styled with your Figma/UI-UX learnings
How to use this roadmap
Don't build all six at once. Pick one you're most excited about, finish it end-to-end (including a README with screenshots and a live demo link), then move to the next. A single polished, documented project outperforms three half-finished ones on a portfolio.
