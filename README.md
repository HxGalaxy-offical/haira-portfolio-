# Haira M A K — Portfolio

Static site: plain HTML, CSS and JavaScript. No build step.
Open `index.html` in a browser, or use a local server (e.g. VS Code Live Server).

## Files

```
portfolio/
├── index.html        Home
├── about.html
├── experience.html   Internships and training
├── projects.html     Three projects with GitHub links
├── certificates.html Filterable certificate list
├── skills.html
├── contact.html      Email, LinkedIn, GitHub
├── resume.html       Printable résumé (Print / Save as PDF)
├── style.css
└── js/script.js      Year, mobile nav, certificate filter
```

## Keep in sync

Update `resume.html`, `experience.html` and `projects.html` together whenever
the résumé changes. Only add items that can be explained in an interview.
